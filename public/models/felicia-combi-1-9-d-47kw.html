Škoda Felicia Combi 1.9 D 47 kW

The Felicia Combi 1.9 D 47 kW combines the type Š 795 five-door passenger estate with the AEF engine. Its fuel system is indirect-injection diesel. Engine code and injection system distinguish this configuration from Felicias with the same displacement or a similar trim name.[1][2]
