Škoda Felicia GLX — Chilean SII A505061

The Chilean assessment code A505061 identifies Felicia GLX with five-door passenger classification and the written equipment selector EQUI. Neither the assessment code nor NORM/EQUI identifies a complete factory equipment package. BT/LL suffixes, where present, do not select physical components without their definitions.[1]
