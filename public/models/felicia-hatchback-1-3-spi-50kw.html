Škoda Felicia hatchback 1.3 SPI 50 kW

The Felicia hatchback 1.3 SPI 50 kW combines the type Š 791 five-door passenger hatchback with the 136B engine. Its fuel system is single-point petrol injection. Engine code and injection system distinguish this configuration from Felicias with the same displacement or a similar trim name.[1][2]
