Škoda Felicia Combi 1.3 MPI 50 kW

The Felicia Combi 1.3 MPI 50 kW combines the type Š 795 five-door passenger estate with the 136M engine. Its fuel system is multipoint petrol injection. Engine code and injection system distinguish this configuration from Felicias with the same displacement or a similar trim name.[1][2]
