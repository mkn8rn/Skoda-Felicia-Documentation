Škoda Felicia hatchback 1.6 MPI 55 kW

The Felicia hatchback 1.6 MPI 55 kW combines the type Š 791 five-door passenger hatchback with the AEE engine. Its fuel system is multipoint petrol injection. Engine code and injection system distinguish this configuration from Felicias with the same displacement or a similar trim name.[1][2]
