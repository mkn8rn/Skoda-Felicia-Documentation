Škoda Felicia LXi 1.3 SPI 40 kW (Netherlands, 1995)

The Dutch-market Felicia LXi listed by importer Pon Mobiel from 1 January 1995 was the five-door hatchback with the 40 kW, 1,289 cm³ single-point-injection petrol engine. This is a dated national sales configuration: its LXi designation and output do not define LXi versions in other markets or later years.[1]

Factory configuration

Felicia LXi listed for the Netherlands, 1 January 1995
BodyFive-door hatchback, factory type Š 791[3]
Engine1,289 cm³ OHV petrol, code 135B
Rated output40 kW
Fuel systemBosch Mono-Motronic single-point injection
TransmissionFive-speed manual
DriveFront wheels
Market and dateNetherlands; price list effective 1 January 1995

The importer’s price schedule pairs the name LXi with the lower-output 40 kW engine in this issue. The period technical sheet identifies the 1.3 fuel system and five-speed manual, front-wheel-drive layout. The 135B code distinguishes the single-point-injection, lower-compression engine version.[1][2]

Identification

Use the body type and engine code together when identifying this specification. LXi alone is insufficient because importer trim names and engine outputs varied by market and period. The published list is a sales date, not a vehicle-production or registration date.
