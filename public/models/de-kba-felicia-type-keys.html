Felicia — German manufacturer and type keys

A German registration identifies a Felicia type by the manufacturer key 8004 together with its three-character type key. KBA distinguishes Felicia, Felicia Combi, Felicia Fun and Felicia Vanplus. The passenger entries share the broad legacy class/body pair 01 / 0200; Vanplus uses class 10 with no printed body code. These codes alone do not identify a factory shell or roof revision.[1][2][3]

Recognition

Compare the complete manufacturer/type pair with the vehicle document. An assignment date belongs to the type key, rather than the vehicle’s build date. These keys do not determine a trim, fuel-metering version, installed restraint package or production/VIN range. The earlier convertible named Felicia has a different manufacturer/type classification and is not identified by these entries.[1]
