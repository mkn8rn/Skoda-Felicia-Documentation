Felicia — Polish recorded chassis classes

The observed prefixes distinguish a five-door hatchback from an ordinary two-door Pickup, broad LX/GLX versions and engine class 136 or AEF. A fixed preparation code describes the shell’s preparation, rather than proving fitted restraints.[1]
