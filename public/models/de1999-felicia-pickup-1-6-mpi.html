Škoda Felicia Pickup 1.6 MPI (Germany, 1999)

Škoda Auto Deutschland’s later model history identifies a 1999 German-market Felicia Pickup generally combined with the 1.6 MPI petrol engine. It reports a new price close to €14,000 and a separately priced partial-leather interior option. This is a dated market configuration; the account does not give a factory order code or vehicle-level build boundary.[1][2]

Documented configuration

1999 German-market Škoda Felicia Pickup 1.6 MPI offer
Market and dateGermany; a Škoda Auto Deutschland retrospective reports the vehicle’s price for 1999. This is not a production date or chassis-number range.[1]
Body and approval typeTwo-seat commercial pickup; type 797. The same type number also appears for the distinct Fun body.[2][3]
Engine offer1.6 MPI petrol; the German history does not print the engine code, displacement or rated output.[1]
Reported 1999 priceClose to €14,000 in the retrospective; it is not a factory identifier.[1]

Equipment option

The same German-market account lists partial-leather upholstery as a €639 option. Its description does not specify an upholstery code or seat-cover part number. The optioned configuration has a separate page: Felicia Pickup 1.6 MPI with partial-leather upholstery (Germany, 1999).[1]

Identification limits

The account describes this as the general German Pickup engine pairing for 1999, not as an engine-by-engine production ledger. It gives no gearbox code, steering-side identifier, order or option code, engine-specific production interval, VIN boundary, or exact body/trim revision. It therefore does not identify a vehicle-specific factory parts set. The 1.6 MPI construction and code description are in the Felicia 1.6-litre engine article.
