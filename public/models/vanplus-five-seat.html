Škoda Felicia Vanplus five-seat version

Škoda Felicia Vanplus five-seat version is one of the two factory seating forms reported for the Felicia Vanplus commercial derivative. The distinction is the number of installed passenger seating positions; the available type designation remains 795 VANPLUS for the commercial body.[1][2]

Identification limits

Škoda’s retrospective records the two- and five-seat Vanplus forms but does not assign engine codes, gearbox codes, markets or production/VIN boundaries to either layout. The seating distinction changes the installed cabin seating arrangement; the shared 795 VANPLUS designation does not identify which layout or its associated parts is present in an individual vehicle.[1]

Israeli five-seat selections

Israeli model 676/610 explicitly records five seats; manufacturer/model code and recorded year distinguish the selections.[4]

  • Israel 1998 Felicia Vanplus LX — model M676/610
  • Israel 1999 Felicia Vanplus LX — model M676/610
  • Israel 2000 Felicia Vanplus LX — model M676/610
  • Israel 2001 Felicia Vanplus LX — model M676/610
