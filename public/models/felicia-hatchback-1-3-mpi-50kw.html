Škoda Felicia hatchback 1.3 MPI 50 kW

The Felicia hatchback 1.3 MPI 50 kW combines the type Š 791 five-door passenger hatchback with the 136M engine. Its fuel system is multipoint petrol injection. Engine code and injection system distinguish this configuration from Felicias with the same displacement or a similar trim name.[1][2]

Body typeŠ 791[1]
Engine136M[2]
Rated output50 kW[2]
Fuel systemMultipoint petrol injection[2]

Grade names describe a market’s equipment offer. In the Dutch January 1995 price list, LXi identifies the 40 kW single-point-injection hatchback; the Dutch 1999 range uses LXi for the 50 kW multipoint-injection car. An “i” suffix therefore cannot identify engine output independently of market and date.[3][4]
