Škoda Felicia Fun 1.3 MPI 50 kW

The Felicia Fun was offered with a 1,289 cm³ petrol engine using multipoint injection and rated at 50 kW. Škoda’s historical specification identifies this as the basic Fun version and associates it with the LX equipment line and a reported Czech price of 304,900 CZK.[1]

Identification limits

The Fun-specific account gives displacement, fuel system and output, but does not provide an engine code, gearbox code, market-order code or chassis/VIN limit for the 1.3 version. Its series-wide production dates and transmission statement therefore do not identify the exact production boundary or installed part set of an individual car.[1]
