BRISK DR15TC spark plug (1329)

DR15TC is a BRISK Extra-series spark plug, product code 1329. BRISK’s vehicle catalogue lists it for multipoint-injection Felicia petrol applications; its product sheet defines the plug’s dimensions.[1]

BRISK uses AMG/AMH with parenthetic 135B/136B MPI descriptions. The dated Škoda technical table identifies B-coded engines as single-point injection and M-coded engines as multipoint injection; the supplier notation does not establish a code equivalence. The original Škoda part number and exact body/grade/build mapping are Unconfirmed. DR15TC-1 has a different suffix and product code.[2][3]
