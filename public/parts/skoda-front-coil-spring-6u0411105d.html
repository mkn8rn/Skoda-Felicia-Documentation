Škoda front coil spring 6U0 411 105 D

CB Auto’s parts catalogue identifies 6U0411105D as an original Škoda front coil spring. Its Felicia application description names the 1.3-litre engine class, a reinforced body and ABS.[1]

The catalogue operator is CB Auto, whose authorised-service and parts/NORA roles are separately identified by Škoda. This is a dealer-listed genuine service-product identity, separate from proof that a particular car received the spring at manufacture.[2][3]

Application and selection

The dealer associates the spring with the Felicia 1.3, reinforced-body and ABS description. This does not define a reinforcement revision or identify an ABS controller, factory option code or production cutoff.[1]

Match the actual spring reference, body and equipment application, seats, axle load and spring/damper working travel. Engine displacement alone does not establish this product. No dated KYB service interval is treated as a factory introduction or body-revision cutoff for the genuine spring.

Service alternative

The dealer description says the original item cannot be ordered and separately presents KYB RA2056 as a non-original alternative. That is a stated dealer service relationship, not a global stock declaration or a factory supersession.[1]

The genuine reference and KYB product retain distinct identities. KYB measurements, packing fields and supplier intervals are not original Škoda dimensions, quantities or production limits. Exact recipient fitment requires the coil-spring replacement requirements.
