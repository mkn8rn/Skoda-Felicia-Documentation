Škoda wheel-bolt cover set 000071215N Z37

Škoda’s current catalogue identifies 000071215N Z37 as a decorative wheel-bolt cover set. Its product-specific application list includes Felicia (1994–2001), without identifying a historic factory installation or an exact Felicia build.[1]

The locking-bolt set contains different cover types for standard and anti-theft bolt heads. Its packaged cover count is not a Felicia’s original bolt or cover quantity. The included removal tool has no separate product code in this record; it is not assigned to either separately sold tool by appearance.[1]

For routine cleaning, the manufacturer permits ordinary detergent and excludes abrasive cleaners and solvents. This is a product-care condition, not a wheel-fastener torque or mechanical service specification.[1]

Application and selection

Match standard versus locking bolt heads, cover engagement and clearance to the actual wheel fastening. Colour and a shared code stem do not make the sets identical.[1]

The application is the manufacturer-listed Felicia family, with exact body, engine, market, steering, original equipment and production/chassis selection Unconfirmed. The current listing does not identify a historically installed product, a factory supersession or original quantity.
