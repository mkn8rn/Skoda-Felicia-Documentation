CDC-A05 external CD changer

CDC-A05 is the external CD-changer designation named by the Casablanca Škoda operating manual. It is a separate audio device controlled through the receiver. The complete order number, hardware revision and original Felicia installation remain Unconfirmed.[1]

Receiver control

Changer mode requires an inserted magazine and is selected with the receiver’s SRC control. The receiver provides disc selection, track selection, audible search, brief track scanning and mixed track playback. In mixed mode, tracks are shuffled within each disc while discs are selected in numerical order. The displayed disc and track indicators describe playback, not the magazine’s total capacity.[1]

Application and installation

The documented relationship is control compatibility with the receiver described in the Casablanca manual. It does not establish a factory-installed changer, a complete Felicia accessory kit, or compatibility with MS 201, MS 401 or every other Casablanca revision. Power and control connections, cable identity, mounting orientation/support, dimensions and installation location are Unconfirmed in this source.[1]

Radio and changer recipient selection requires a matched receiver and changer revision, their approved connection cable and mounting arrangement. A common commercial name is insufficient to select a vehicle loom or infer interchangeability.
