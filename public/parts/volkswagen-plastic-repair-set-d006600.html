Volkswagen plastic repair set D 006 600

The July 1996 Caddy Pickup publication names D 006 600 as a repair set for the manufacturer’s GRP enclosure and rear wing doors.

Contents

  1. Service identity
  2. Documented application
  3. References

Service identity

The printed service-set identifier is D 006 600. The set is recommended for repair of the described glass-fibre/resin laminate; it is not a factory-installed hardtop part. Complete contents, chemical specifications, packaging quantity, handling instructions, later suffixes and supersession history remain Unconfirmed.[1]

Documented application

The source application is the manufacturer GRP hardtop. A service-set reference does not identify replacement body panels, an authorised road conversion or an equivalent material for another enclosure.
