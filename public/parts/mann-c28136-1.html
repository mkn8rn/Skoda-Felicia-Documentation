MANN-FILTER C 28 136/1 air-filter element

C 28 136/1 is a MANN-FILTER air-filter element offered as a service replacement. The manufacturer records its dimensions and the following Felicia applications.[1]

MANN’s catalogue groups Felicia applications without identifying a national grade or a body-specific row. The intervals are supplier selections, not proof of the first or last factory build. The original Škoda identifier, factory quantity and production/VIN/option boundaries are Unconfirmed. Its 40 kW code grouping does not expressly identify 135M; use on that exact engine-code class remains Unconfirmed. The 1.3 MPI condition must not be transferred to the SPI housing merely because the catalogue’s code column includes B-coded labels.[2]
